# STM32 Blue Pill Bare-Metal LED project:-
This is a self-taught embedded systems project built during my 3rd semester. It configures the microcontroller entirely via memory-mapped registers without using standard HAL libraries or an operating system.
## Deep Technical skills Demonstrated:-
Register-level control: Directly programmed the 'CRL' and 'CRH' configuration registers to control the hardware pins.
Bus Architecture : Enabled peripheral clock gating via  the RCC registers on the AHP/AHB bus structure.
## Hardware Environment:-
Microcontroller: STM32F103C8T6(BLUEPILL)
Debugger Link: ST-LINK V2
